# 03_DFT

Gaussian 16 input files for CNP0301965.2 (42 atoms, C19H19N1O3).

| File | Calculation |
|---|---|
| `opt_CNP0301965.gjf` | geometry optimization |
| `UV_CNP0301965.gjf` | TD-DFT on the optimized geometry |

Level of theory: B3LYP/6-311++G(d,p), charge 0, multiplicity 1, `%nprocshared=16`,
`%mem=64GB`. The route lines at the top of each `.gjf` file are the exact settings used.
